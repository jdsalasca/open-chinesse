Este directorio reúne la literatura que sostiene las decisiones de producto. No es
una bibliografía decorativa: cada documento termina en decisiones concretas de
implementación, y `07-conclusiones-diseno.md` las consolida.

## Criterios de inclusión

- Metaanálisis, estudios experimentales o benchmarks con datos públicos.
- Preferencia por trabajos sobre L2 chino o vocabulario de lenguas extranjeras.
- Se anotan los límites de cada estudio; nada se presenta como conclusión única.
