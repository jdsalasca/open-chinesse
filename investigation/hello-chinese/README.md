# HelloChinese — teardown y colaboración

Este dossier analiza el referente del mercado para dos cosas: aprender de lo que
hace bien y proponer una colaboración honesta. **Open Chinesse no está afiliado a
HelloChinese**; las marcas y el producto son de sus dueños.

## Resumen en una frase

HelloChinese es la mejor app móvil de chino para principiantes; **no tiene una
versión web abierta**, y ahí hay espacio para una alternativa complementaria, no
competidora.

## Regla de respeto

- No copiamos activos, textos ni código propietario.
- La paleta se usa como **referencia de género visual** (verde menta, pasteles,
  formas redondeadas), no como calco.
- Cualquier colaboración se plantea desde la atribución y el beneficio mutuo.
