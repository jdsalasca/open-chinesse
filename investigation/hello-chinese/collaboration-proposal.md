# Propuesta de colaboración

Documento de una página para abrir conversación con HelloChinese (o cualquier
editor del sector). **No implica afiliación ni respaldo.**

## Qué es Open Chinesse

Una app web abierta para aprender mandarín desde cero: HSK 1 y 2 completos,
repaso espaciado FSRS, audio, práctica de producción escrita y progreso
sincronizado. Código MIT, currículo propio y un dossier de investigación con
fuentes primarias.

## Qué aportamos

1. **Acceso sin instalación.** Un enlace funciona en escritorio, Chromebook, Linux
   y aulas con equipos prestados, donde una app nativa no llega.
2. **Transparencia metodológica.** Cada decisión de producto está documentada con
   su paper y su límite (`/investigation`).
3. **Portabilidad.** Progreso exportable; sin cuentas obligatorias para empezar.
4. **Base técnica reutilizable.** SPA React + backend Spring Boot con OAuth2,
   empaquetable en cualquier institución.

## Qué pediríamos

| Opción                 | Formato                                           |
| ---------------------- | ------------------------------------------------- |
| Contenido con licencia | Audio de nativos o listas curadas con atribución  |
| Interoperabilidad      | Exportar/importar progreso entre ambas apps       |
| Investigación conjunta | Medir retención a 30 días con el mismo protocolo  |
| Distribución           | Enlace "versión web" desde su web para escritorio |

## Qué no haríamos

- Copiar activos, textos, código ni diseño propietario.
- Declarar afiliación sin contrato.
- Usar su marca en publicidad comparativa.

## Modelo de sostenibilidad

- Núcleo abierto (MIT) y autoalojable.
- Servicios opcionales: instancia gestionada, paneles para docentes, contenido
  ampliado.
- Sin vidas, sin leaderboards, sin notificaciones: la ética del producto es parte
  de la propuesta.

## Siguiente paso concreto

Una llamada de 30 minutos con tres preguntas:

1. ¿Les interesa una versión web complementaria o la consideran competencia?
2. ¿Hay contenido que licenciarían con atribución?
3. ¿Compartirían datos agregados de retención para una comparación abierta?
